# Data Engineering Zoomcamp

This repository documents my progress through the Data Engineering Zoomcamp by DataTalks.Club, led by Alexey Grigorev.

The goal of this repository is to track my learning journey and practical implementations across the main topics of modern data engineering, including containerization, workflow orchestration, data ingestion, data warehousing, analytics engineering, batch processing, and streaming. It includes Docker, Terraform, Kestra, BigQuery, dbt, Spark, Kafka, learning about everything from setting up infrastructure to working with streaming data.

👩🏽‍💻 [Link to the course](https://github.com/DataTalksClub/data-engineering-zoomcamp/tree/main)
